DocAgent - run in 2 steps
1. Install Python 3 (python.org) if you don't have it.
2. Open a terminal in this folder and run:
      python3 docagent.py      (Windows: python docagent.py)
Then open dashboard.html in your browser. Results also in docs.csv.
Your API key is in the hidden file .env (never share this folder publicly).
Add your own .txt documents to the docs/ folder and run again.
